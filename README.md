Solmar Bay — an original open-world crime game. Drive through a coastal city, outrun the police, and complete a 5-mission story chain: taxi fares, a hot-wheels heist, a dockside deal, a getaway chase, and the Bayfront Heist. Wanted level, traffic, pedestrians, day cycle, and a save system included. No Rockstar/GTA assets — the city, names, story, and art are all original.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
